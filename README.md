# STREETFORM

Статический магазин кроссовок, одежды и аксессуаров.

## Сайт

- `index.html` — витрина, фильтры, поиск, корзина и подробные карточки товаров.
- `styles.css` — адаптивный визуальный стиль.
- `script.js` — каталог, корзина и локальная админ-панель.
- `catalog.json` — общий опубликованный каталог, который сайт подгружает при открытии.

Сайт загружает свежий `catalog.json`, поэтому товары из Telegram-каталога видны посетителям сайта.

## Telegram-бот с кнопками

Бот умеет добавлять товары, менять цены, редактировать детали, менять фото и удалять товары через кнопки. Он сохраняет изменения в `catalog.json`.

Для полностью автоматической синхронизации каждого будущего изменения бот должен работать на постоянном сервере с правом обновлять опубликованный `catalog.json` или через backend API. GitHub Pages сам по себе только раздаёт файлы и не принимает записи от бота.
